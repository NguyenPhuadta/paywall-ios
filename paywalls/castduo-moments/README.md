Serve index.html over HTTP. Base frame 390×844. Native system font; no Apple font redistributed.

Use ?review=1&device=compact for SE, or device=440x956,420x912,430x932,402x874,393x852,default,414x896,375x812. Use ?view=board for state review. State/eligibility query controls use the same review bridge as the stock library.

Purchase and restore are simulations. Product IDs, real prices, policy URLs and native StoreKit are not configured.
